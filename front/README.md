# NOTOX — application mobile

Le guide des fonctionnalités, des parcours d’utilisation et du démarrage du projet se trouve dans le [README principal](../README.md).

## Démarrer l’application

```bash
npm install
cp .env.example .env
npm start
```

Définissez `EXPO_PUBLIC_API_URL` dans `.env` pour joindre le backend. Pour un appareil physique, utilisez l’adresse réseau locale de l’ordinateur qui exécute le serveur, et non `localhost`.
